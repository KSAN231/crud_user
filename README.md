# Users CRUD — консольное приложение для управления пользователями

## Описание

Учебный проект на Python для работы с пользовательскими данными. Приложение позволяет добавлять, просматривать, искать, редактировать и удалять пользователей через консольное меню.

Проект создан для практики работы с функциями, структурами данных, JSON-файлами и базовыми CRUD-операциями.

## Возможности

- **Create** — добавление новых пользователей.
- **Read** — просмотр списка пользователей и поиск по имени.
- **Update** — редактирование данных пользователя.
- **Delete** — удаление пользователей.
- Автоматическое назначение идентификаторов (ID).
- Сохранение данных в JSON-файл.
- Загрузка данных при запуске приложения.
- Обработка некоторых ошибок при чтении JSON и вводе данных.
- Управление приложением через консольное меню.

## Запуск проекта

1. Установите Python.
2. Склонируйте репозиторий:

   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   ```

3. Перейдите в папку проекта:

   ```bash
   cd <ПАПКА_ПРОЕКТА>
   ```

4. Запустите основной файл приложения:

   ```bash
   python main.py
   ```

   Если основной файл называется иначе, используйте его имя.

## Хранение данных

Пользовательские данные хранятся в JSON-файле. При добавлении нового пользователя приложению назначается следующий ID на основе существующих записей.

## Цель проекта

Закрепить базовые знания Python на практике, научиться разделять логику приложения на функции и реализовать основные операции CRUD с сохранением данных между запусками.

## Статус проекта

Учебный проект. Разрабатывается в рамках изучения Python и backend-разработки.
